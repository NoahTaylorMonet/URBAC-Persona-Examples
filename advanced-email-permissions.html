Advanced Email Actions — URBAC Permissions

Microsoft Defender Unified RBAC · GCC High MDO · scenarios and required permission combinations

The permissions

  • Email & collaboration advanced actions (Manage) — move email to Junk / Deleted Items / Inbox; soft and hard delete.
  • Response (Manage) — required to take remediation actions from Advanced hunting query results.
  • Email & collaboration metadata (Read) — headers, sender/recipient, verdicts in hunting surfaces.
  • Email & collaboration content (Read) — view and download message body and attachments.
  • Email & collaboration quarantine (Manage) — view and release email from quarantine.
  • Detection tuning (Manage) — manage the Tenant Allow/Block List (TABL), custom detections, alert tuning, threat IoCs.
  • Alerts (Manage) — assign, classify, comment on, and change the status of incidents and alerts.
  • Core security settings (Manage) — configure MDO threat policies and protection settings.
  • System settings (Manage) — create and manage user and priority-account tags.
  • Authorization (Manage) — create and manage Unified RBAC roles and assignments.
  • Microsoft Entra Security Reader — required in this GCC High environment for Threat Explorer to load.

Scenarios and required permission combinations

ScenarioRequired permissionsNotes
Investigate an email without acting metadata (Read) + content (Read) Read headers, verdicts, campaign; open and download body and attachments.
Remediate from Threat Explorer advanced actions (Manage) Take action wizard, up to 200,000 emails per query. Add Read permissions to see evidence first.
Remediate a single message (Email entity page) advanced actions (Manage) Action taken from the entity / summary panel.
Remediate from Advanced hunting advanced actions (Manage) + Response (Manage) Take action on KQL query results. Hunting surface adds the Response requirement.
Hard delete (purge) a campaign advanced actions (Manage) + content (Read) Hard delete isn't a separate action, but Unified RBAC requires content (Read) to hard delete. Add Response (Manage) if run from Advanced hunting.
Release a false positive from quarantine quarantine (Manage) Not an advanced action. Add content Read to preview before release.
Block/allow sender, domain, URL, hash (TABL) Detection tuning (Manage) Tenant-wide, independent of remediation.
Full email remediation across all surfaces metadata (Read) + content (Read) + advanced actions (Manage) + Response (Manage) Investigate, then act from Threat Explorer, Email entity, and Advanced hunting.
